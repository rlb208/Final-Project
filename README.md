# Dataset Links and Descriptions

[Arrests for Major Crimes Dataset](https://data.wprdc.org/dataset/bce15079-618a-4bf3-badf-8aa372c3aea2/resource/8ce92a4b-fa62-45c3-8cee-cc58fefede75/download/arrests-for-major-crimes-1972.csv)
  
    Dataset shows a list of Pittsburgh neighborhoods, their populations, and their overall crime rates.

[Non-Traffic Citations](https://data.wprdc.org/datastore/dump/6b11e87d-1216-463d-bbd3-37460e539d86)

    Dataset shows a list of non-traffic citations and includes the neighborhood/location it happened in.

[Arrests](https://data.wprdc.org/datastore/dump/e03a89dd-134a-4ee8-a2bd-62c40aeebc6f)

    Dataset shows a list of arrests in the Pittsburgh areas, along with the neighborhood and location it occurred in.


This repository includes three datasets that show the amount of crime in certain Pittsburgh neighborhoods. The neighborhood with the least amount of crime is considered the "best" neighborhood.
